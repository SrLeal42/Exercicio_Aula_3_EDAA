# Exercicio_Aula_3_EDAA
Ordem dos Laços: Implementar a multiplicação nas duas ordens e medir. Matriz esparsa: Implementar a representação por tripas, com leitura, escrita e percurso dos não nulos. Dez linhas escritas: Medir memória e tempo das duas representações e dizer a partir de qual densidade a esparsa deixa de valer a pena.
